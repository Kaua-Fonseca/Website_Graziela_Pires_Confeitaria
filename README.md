# Graziela Pires Confeitaria

Site institucional e catálogo visual para a Graziela Pires Confeitaria, desenvolvido com **Next.js + React + TypeScript**.

## Tecnologias

- Next.js 15 (App Router)
- React 19
- TypeScript
- CSS global responsivo

## Executar localmente

Requisitos: Node.js 20 ou superior e npm.

```bash
npm install
npm run dev
```

Acesse http://localhost:3000.

## Gerar build de produção

```bash
npm run build
npm start
```

## Escopo atual

Esta versão é a migração do protótipo visual do Figma Make para Next.js. O foco atual é o front-end: páginas e navegação visual, catálogo, showroom e formulário de orçamento. Banco de dados, autenticação administrativa e edição real dos produtos ainda não estão conectados.

## Observação

A branch `migracao-nextjs-frontend` contém a migração em andamento. A branch `main` permanece preservada como versão original do Figma Make.
