# Graziela Pires Confeitaria

Projeto de site institucional e catálogo da confeitaria, migrado do protótipo Figma Make para Next.js.

## Stack
- Next.js 15 com App Router
- React 19
- TypeScript
- CSS global em `app/globals.css`
- Página principal e interações de interface em `app/page.tsx`

## Comandos
- `npm install`: instalar dependências
- `npm run dev`: executar o ambiente local
- `npm run build`: validar e gerar build de produção
- `npm start`: executar a build de produção

## Escopo atual
O trabalho nesta etapa é somente o front-end. Não presumir que há banco de dados, login, painel administrativo ou integração real com WhatsApp. Antes de adicionar integrações, confirmar os dados e requisitos com o usuário.

## Boas práticas
- Manter a interface responsiva e acessível.
- Preservar o estilo visual artesanal e elegante já definido no CSS.
- Não adicionar segredos ou credenciais ao repositório.
- Testar `npm run build` após alterações quando possível.
